# 书架 · 小说阅读器

GitHub Pages 上的小说阅读网站，外加一个只有你能用的编辑器。

- 读者页面：`https://你的用户名.github.io/仓库名/`
- 编辑器：`https://你的用户名.github.io/仓库名/editor.html`

## 第一次部署

1. 在 GitHub 新建一个**公开**仓库（例如 `arcadia_reader`），创建时勾选 **Add a README file**。仓库不能是空的，否则编辑器没法提交。
2. 解压压缩包，把 `arcadia-reader` 文件夹**里面的所有东西**拖进仓库根目录上传。包括 `index.html`、`editor.html`、`.nojekyll`、`assets`、`data` 和 `covers`。不要上传 zip 本身，也不要多套一层文件夹。
   - `.nojekyll` 是隐藏文件，网页上传可能看不到它。如果漏传了，就在仓库里点 Add file → Create new file，文件名填 `.nojekyll`，内容留空即可。
3. 打开仓库 Settings → Pages，把 Source 设为 **Deploy from a branch**，分支选 `main`，文件夹选 `/ (root)`，然后保存。
4. 大约 1 分钟后，打开上面的网址就能看到书架。

## 令牌

百科用的令牌如果没有授权这个新仓库，编辑器会显示 404。有两种办法：

- 编辑原来那个令牌，在 Repository access 里把新仓库也勾上；
- 或者新建一个 Fine-grained token：Only select repositories 只选这个仓库，Contents 设为 **Read and write**。

## 编辑器用法

- **新建小说**：可以点“＋ 新建小说”后手动填写，也可以直接把 TXT / DOCX 拖进书架页，编辑器会自动新建一本并分好章节。
- **封面**：把图片拖进封面框，或者点击封面框选择文件。图片会自动压缩成最长边 1200px 的 JPG。
- **分章规则**：章节标题要单独占一行。
  - 能识别的章节标题：“第X章 / 回 / 节 / 话”、序章、楔子、尾声、番外，以及 Word 的“副标题”或“标题 2”样式。
  - 能识别的篇或卷：“第X篇 / 部 / 卷”，以及 Word 的“标题”或“标题 1”样式。
  - 导入前会先显示预览，可以在预览里修改标题、取消勾选某些章节，也可以选择“追加”或“替换全部”。
- **正文格式**：每一行是一个段落。单独一行的“——”或“***”会显示成分隔线。
- **草稿**：所有修改都会自动保存在这台电脑的浏览器里，关掉网页也不会丢。点右上角的“发布”之后，读者才能看到这些修改。
- **隐藏**：勾选“暂时隐藏”后，读者在书架上看不到这本书，相当于下架。

## 读者功能

- 根据屏幕大小和字号自动分页，底部显示“第几页 / 共几页”和全书进度。
- 可以调整字号、行距、字体（宋体 / 黑体）和背景（白色 / 纸张 / 夜间 / 护眼绿），文字颜色会自动适配背景。
- 目录里，读过的章节标 ✓，正在读的章节标“在读”。
- 会自动记住读到哪一页，下次打开直接从那里继续。书架页也会显示阅读进度。
- 翻页方式：点击屏幕左右两侧、键盘方向键或空格、手机上左右滑动。

阅读进度只保存在读者自己的浏览器里，换一台设备需要重新开始。

## 文件结构

```
data/library.json            书架和所有小说的信息
data/novels/<书ID>/<章ID>.txt 每一章的正文
covers/<书ID>.jpg            封面
```
